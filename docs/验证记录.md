## 尚未验收

- uni-app 的 UTS 接入源码与 Android 核心 AAR 已提供；本次没有对应 HBuilderX 的自定义基座编译及运行结果。当前 App 的 WebView 集成测试不能替代这一项。
- 传统 UniModule 仅提供可选源码；官方旧示例 SDK 缺少所需 UniModule API，没有生成其发行 AAR。
- 尚未在 Android 11–14、不同厂商真机及真实游戏完成整场战斗/完整循环验收。截图识别和模拟手势通过，不等于这些项目已通过。
- 系统图片选择器的人工作业、真实使用中的授权切换、长时间后台运行仍需真机验收；已覆盖直接 content URI 图片导入和服务重新绑定。

## 复现

常规构建见 README。安装 demo 与 host-test 及其 AndroidTest APK 后，在专用测试模拟器执行：

```powershell
adb -s emulator-5582 shell am instrument -w com.yuan.follow.demo.test/com.local.yuanatlas.PluginChecks
adb -s emulator-5582 shell am instrument -w com.local.yuanatlas.plugintest.test/com.local.yuanatlas.HostPluginChecks
```

宿主测试会临时切换专用模拟器的无障碍服务设置，仅在隔离测试设备运行。检查输出中的 PASS 与异常文本，不能仅依据 adb 退出码判断成功。
